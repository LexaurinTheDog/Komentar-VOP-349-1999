# Komentář k zákonu č. 349/1999 Sb., o Veřejném ochránci práv

Odborný komentář k **zákonu č. 349/1999 Sb., o Veřejném ochránci práv** — předpisu zakotvujícímu český ombudsmanský model: neformální ochranu před jednáním úřadů v rozporu s právem či principy dobré správy, šetření s širokou součinnostní povinností úřadů a sankci zveřejněním, doplněné o role národního preventivního mechanismu a tělesa pro rovné zacházení.

Konsolidované znění: dokument e-Sbírky `SB-1999-00349_2025-07-01`.
